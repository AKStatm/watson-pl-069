## 1) Lead ID formula (Column A)

Your headers are on row 2, data starts at row 3.
Put this in **A3**, then drag down:

### Option A (recommended) — prefix from Category (Column C)
``` 
=IF(B3="","",
  IFS(
    REGEXMATCH(LOWER(IF(C3="", "plumber", C3)), "plumb"), "PL",
    REGEXMATCH(LOWER(C3), "electric"), "EL",
    REGEXMATCH(LOWER(C3), "ac|hvac|cool"), "AC",
    REGEXMATCH(LOWER(C3), "salon|beauty"), "SL",
    REGEXMATCH(LOWER(C3), "restaurant|cafe|food"), "FD",
    TRUE, UPPER(LEFT(REGEXREPLACE(IF(C3="", "XX", C3), "[^A-Za-z]", ""), 2))
  )
  & "-" & TEXT(COUNTIF($B$3:B3, "<>"), "000")
)
```

Examples:
- Row 3 → PL-001
- Row 4 → PL-002
- First electrician row → EL-00x

### Option B (simple, all plumbers)
```
=IF(B3="","","PL-"&TEXT(COUNTIF($B$3:B3,"<>"),"000"))
```
