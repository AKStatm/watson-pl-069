# Lead Demo Template — Connect & Run

## What this project is
Next.js demo website engine for Pakistan local business leads.
One template + niche configs (70+ niches). Fill `src/config/lead.json` → site becomes that business.

## Run locally
```bash
cd lead-demo-template
npm install
npm run dev
```
Open http://localhost:3000  
Preview niches: http://localhost:3000/niches  
Example: http://localhost:3000/?niche=electrician

## Customize a lead (manual)
Edit `src/config/lead.json`:
- leadId, businessName, nicheId, phone, whatsapp, address, cityArea
- rating, reviewCount, topServices, about, workingHours

`nicheId` must match a key from the niches registry (plumber, salon, dentist, etc.).
